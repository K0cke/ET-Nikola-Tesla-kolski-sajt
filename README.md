🛠 Korišćene tehnologije

HTML5 – Struktura stranica.
CSS3 – Dizajn, Flexbox, Grid sistemi, Media queries za responsivnost.
JavaScript – Interaktivnost (hamburger meni, modalni prozori, skrolovanje).
FontAwesome – Ikone.
Google Fonts – Tipografija.
Bootstrap – Korišćen za određene komponente radi bržeg i čistijeg koda.

🚀 Ključne karakteristike

Responsive Design: Sajt je u potpunosti prilagođen svim uređajima (mobilni telefoni, tableti, desktop).
Intuitivna navigacija: Implementiran "hamburger" meni za mobilne uređaje i laka navigacija kroz sekcije sajta.
Interaktivni Modali: Iskačući prozori (modali) za brzo informisanje o procesu upisa bez napuštanja stranice.
Strukturirani podaci: Jasno organizovane sekcije sa informacijama o smerovima, minimalnim bodovima za poslednje 3 godine i veštinama koje se stiču.
Optimizovan UI/UX: Korišćena moderna paleta boja i tipografija za bolje korisničko iskustvo.

Ovaj projekat predstavlja modernizovanu, responsivnu web prezentaciju za Elektrotehničku školu "Nikola Tesla" u Nišu. Cilj projekta je bio da se budućim učenicima i roditeljima pruži pregledan, moderan i lak pristup informacijama o obrazovnim profilima, bodovnim pragovima i procesu upisa.
